# Ждун — искусство подождать

Статический сайт с интерактивным Ждуном и дождём из дельфинов. Three.js 0.180.0, OrbitControls, MeshoptDecoder и Rapier 0.19.3 находятся в `dist/vendor/`; модели и библиотеки загружаются с того же сервера.

## GitHub Pages

Сайт: https://iamnhuman.github.io/dolphin-rain/

В **Settings → Pages → Build and deployment** используется **Deploy from a branch**, ветка **main**, папка **/ (root)**. После push GitHub Pages публикует изменения автоматически.

Корневой `index.html` перенаправляет на `./dist/`, где находится готовый сайт. `.nojekyll` отключает обработку Jekyll. Все пути относительные, поэтому модели, ES-модули и физика работают под адресом проекта `/dolphin-rain/dist/`. Сборка и установка зависимостей для публикации не нужны. README остаётся документацией репозитория и больше не используется как главная страница сайта.

## Запуск

Из этой папки:

```sh
python3 -m http.server 4173 --directory dist --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173. Открытие HTML как `file://` не поддерживается из-за загрузки ES-модулей и модели.

## Управление

- Мышь / один палец — вращение.
- Колесо / два пальца — приближение.
- Кнопки под моделью — вращение, приближение и исходный ракурс.
- Кнопки «Спереди», «Сбоку», «Сзади» — готовые ракурсы.
- Солнце / луна — светлая и тёмная студия.
- «Остановить» / «Включить» — дождь из дельфинов. После остановки оставшиеся дельфины продолжают падать и исчезают.
- «Сила дождя» — три уровня интенсивности.
- При фокусе на канвасе: стрелки — вращение; `+` / `-` — масштаб; `R` — сброс; пробел — автоматическое вращение.

Ждун содержит 1 875 364 треугольника; его видимая геометрия и PBR-карты сохранены. Для дельфинов подготовлена копия на 12 000 треугольников с текстурами 1024 px: она рисуется через InstancedMesh с общими геометрией и материалом. Исходный дельфин сохранён в `source-assets/dolphin-original.glb`.

## Физика

Rapier рассчитывает гравитацию, вращение, трение и отскоки с фиксированным шагом 1/120 с; положение и ориентация интерполируются для отрисовки. CCD предотвращает пролёт быстрых дельфинов через поверхности. Ждун — неподвижная треугольная поверхность из 20 000 треугольников, подготовленная по исходной модели и преобразованная в ту же систему координат. Дельфин — динамическое тело из шести выпуклых секций; тела сталкиваются с Ждуном, полом и друг с другом. У каждого разные размер, начальная скорость, вращение и упругость, а слабый боковой ветер добавляет разнообразие траекторий.

После первого контакта с полом дельфин остаётся на 0.7–1.3 с, затем растворяется за 0.5 с; физическое тело и коллайдеры удаляются. Число тел ограничено: 26 на мобильном экране и 40 на большом. Защитный лимит жизни 12 с очищает застрявшие тела. Симуляция приостанавливается в скрытой вкладке. Когда дождь выключен и все тела исчезли, отрисовка снова работает по запросу.

## Проверка

```sh
npm test
```

Шесть тестов используют настоящие коллизионные модели и проверяют свободное падение, отскок от пола на высокой скорости, столкновения с головой и животом Ждуна, столкновения дельфинов, независимость от частоты кадров и освобождение физических тел.

`npm run prepare-assets` повторно готовит оптимизированного дельфина и коллайдер Ждуна. Скрипт использует сохранённые исходники, vendored Meshoptimizer 0.24.0 и macOS `sips` для уменьшения текстур.

Для шрифта используется Google Fonts с системным запасным вариантом.

Статическая публикация использует папку `dist/`. Идентификатор Sites хранится в `.openai/hosting.json`.
